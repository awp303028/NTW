# 新寶島 · 城市生活版 v3

目前版本入口為 dist/index.html，透過靜態網站服務開啟。採繁體中文、手機優先介面；插畫為 PNG、按鈕為 CSS、股價走勢為 Canvas，沒有 SVG。

## 已實作
- 移除角色抽卡、編隊、戰鬥；12 張動物插畫改作工作職人。
- 每輪三份不同工作，隨機 1–5 星，每分鐘薪資 30 / 55 / 90 / 140 / 220 新台幣，體力消耗 1 / 2 / 3 / 4 / 5。選擇 1、5、10、30 分鐘，一次接一份、預扣體力，到時自動結薪，離線回來補結算。
- 完工有 85% 機率獲得可販售小物，並累積社會歷練及納稅點數。
- 體力上限 100，每 5 分鐘恢復 1 點。商店補給購入背包後使用。
- 賓狗賓狗每 5 分鐘從 1–80 抽出 20 個不重複號碼，提供基本選號、超級獎號、大小、單雙。遊戲自訂獎金表在介面公開。
- 大樂透選 6 / 49 加特別號，台灣時間每天 00:00、12:00 開獎，固定獎金表，取最高一項獎。
- 餃子老虎雞：8 種等機率圖案、三軸相同中獎，總中獎率 1 / 64，指定圖案三連為 1 / 512，各圖案倍率公開。
- 商店補給、背包販售、一番賞。一番賞獨立機率 A 1%、B 4%、C 20%、D 75%，不是有限籤池。
- 五檔虛構台股風格股票，每小時更新、單次漲跌不超過 10%；整股買賣、成本與已實現損益，1 張為 1,000 股。
- Q 版台灣地圖與 22 縣市選擇；城市人口及等級是示範資料。
- 拍賣行保留待設計入口。黃金保留顯示及說明，尚無實際儲值，不能兌換遊戲新台幣。

## 試玩範圍
全部新台幣、物品、彩券與股票均為無現金價值的遊戲模擬，未串接真實金流、彩券或證券。酒館及股市只使用遊戲內賺取的新台幣。

進度存在此瀏覽器 localStorage（new-formosa-life-v3），首次承接舊版城市及部分資源，舊存檔保留。不同裝置不共用。開獎與行情依裝置種子和時段產生一致結果，重新整理不重抽；票券只結算一次。

這是前端可玩原型，尚未接入 LINE 登入、多人帳本、官方行情後台或正式金流。LIFF 正式上線仍需 LINE channel / LIFF ID、HTTPS 入口、伺服器身分驗證、資料庫及伺服器權威時間、隨機結果、資源結算。前端時間與存檔可修改，不可作正式營運帳本。

## 維護與驗證
economy.js 管理核心規則；life.js 管理互動；city-map.js 管理地圖；life.css 管理新版外觀。README-V2.md 為歷史紀錄，ART-V2-PROMPTS.json 記錄插畫。

通過 22 項核心檢查，涵蓋離線結薪、單次入帳、體力及補給、物品販售、開獎號碼與獎項、台灣時間邊界、三軸機率、一番賞、行情與股票成本、黃金隔離，並檢查桌面與手機介面。
