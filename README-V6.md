# 新寶島：離鄉背井更新

在探索台灣地圖選擇其他縣市，按「離鄉背井・加入 XX市」，檢視損失後確認搬遷。取消或關閉視窗不搬遷。

- 生活存款保留 10%，小數至分無條件捨去。負餘額須先清償。
- 個人累積納稅歸零，個人等級回到 1。已領取的等級獎勵保留領取紀錄，避免反覆搬遷重領。
- 原城市只扣除此玩家的納稅貢獻；城市等級與設施依剩餘稅額重新計算。
- 清空工作小物、一番賞獎品、補給及報紙，包含黃金購得物品。
- 黃金帳戶餘額、電量、進行中工作、彩券及股票部位保留；之後產生的稅收歸新城市。
- 職缺依新城市等級重新產生；每日限購與刷新次數不重置。
- 確認期間若工作完成或存款、包包等變動，會要求重新檢視損失，避免扣除未確認的物品。重複確認不會再次扣款。
- 第一次加入城市免費；既有存檔保留，首次讀取建立個人城市貢獻紀錄。

目前仍為本機存檔預演，跨玩家共用城市帳本尚未串接。測試包含 8 項搬遷交易檢查與既有 39 項遊戲及介面檢查。完整原規格見 README-V5.md。
