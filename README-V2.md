# 新寶島 · 動物職人版 v2

裝置端單機試玩，使用 HTML / CSS / JavaScript。可直接開啟 `dist/index.html` 或透過本機網站伺服器遊玩。角色與地圖均為 PNG，沒有 SVG；資源圖示以 CSS 製作。

## 本次更新
- 12 位動物職人，每職業各 1、2、3 星，每位獨立 1024×1536 卡圖。
- Q 版台灣地圖，22 縣市可點選；區域篩選、城市居民、等級與設施資訊。居民與其他城市資料為示範值，非即時線上人數。已加入城市的存檔可瀏覽全島，不能任意換城。
- 資源統一為新台幣、社會歷練、納稅，均有圖示。遊戲新台幣是虛擬資源，不是可提領貨幣。
- 體力上限 100；PVE、競技每次消耗 10。每 5 分鐘恢復 1；編入輔助型後，每 3 分 20 秒恢復 1。離線恢復，滿體力不累積額外恢復。
- 初始元氣補給包 3 份，每份恢復 30；體力高於 70 時不可使用，以免溢出。
- 付費黃金獨立餘額與四種儲值方案草案。黃金初始 0，PVE／競技／掛機不產出。商店僅展示方案，未接金流，付款按鈕停用，不扣款、不發放黃金。
- 免費招募券：新存檔 10 張，每次勝利 1 張。抽卡消耗每次 1 張，10 連為 10 張。黃金兌換檢查餘額；正式黃金取得需待金流後端。
- 舊存檔保留城市、角色、等級與資源；舊免費寶石每 160 轉 1 張招募券，不轉為黃金。

## 保留的玩法
8 小時離線收益、職人升級最高 Lv.30、逐關 PVE、模擬 3V3 競技、15 回合上限、城市納稅建設、突襲演練。城市戰為獨立籌備入口，尚未實作多人對戰。

## LINE 與正式付款
`dist/config.js` 留有 `liffId`；填入正式 ID 並設定可供玩家存取的 HTTPS Endpoint URL 後，現有 SDK 初始化與登入入口可供後續串接。尚未驗證實際 LINE 登入。

正式上線尚需：伺服器 LINE 身分驗證、多人玩家／城市資料庫、伺服器資源與戰鬥結算、防作弊、支付商戶與付款頁、伺服器驗證金流回呼、訂單冪等入帳／退款。不得信任 localStorage 的黃金或資源作為正式帳本。此版無實際付款功能，不接受卡號或其他支付資料。
