# 新寶島 · 島民成長與包包版 v5

目前版本以本文件及 dist/ 內容為準，舊版 README 為歷史紀錄。遊戲貨幣、提示、帳目與圖示統一改稱「寶島幣」。沿用原本存檔鍵 new-formosa-life-v4，資料版本升為 5，不重置工作、物品、股票、城市、稅金或開獎期別。

## 玩家 ID、等級與普發
左上角可修改 ID，允許 2～20 字中英文字、數字、空格、底線及連字號。修改顯示名稱不會更換存檔。輸入會驗證並安全呈現，沒有跨玩家唯一性檢查。

玩家等級改按累積納稅，與城市等級分開，最高 100 等。第 1～10 等的累積門檻為 0、20、50、100、180、300、480、730、1,050、1,500。第 11 等起，每級新增需求為 round(600 × 1.12^(等級−11))，第 100 等累積門檻 134,456,170。每 5 級取得新稱號，最高稱號「新寶島傳說」。完整門檻表可在玩家資料內展開。

每升一級，以該級累積納稅門檻的 5% 普發生活存款，保留 2 位小數；跨級逐級補發，按門檻計算使一次大量納稅與分次納稅的總獎勵相同。獎勵本身不再計稅。已發等級記錄在存檔，升級通知只作提示，關閉、重新整理不會再次付款。舊版已累積稅金會補發達標等級的獎勵。

番茄日報 200 寶島幣、牛番茄報 15 黃金，各每日限購 5，台灣時間 00:00 重置。購入包包後閱讀，即新增一份按目前城市加成的工作，不再扣刷新費或电量，不影響原有工作。報紙可超過城市每次刷新數量，但未接工作總量上限 50；滿額或尚未選城市時不消耗報紙。整批刷新會替換未接職缺，包括報紙發現的工作。

## 酒館
賓狗改為自行輸入 1～1,000,000 寶島幣整數，原獎金倍率、娛樂稅及單期上限沿用；不要求為 25 的倍數。

餃子老虎雞三軸出現餃子、老虎、雞各一個即可，6 種排列皆中獎，重複圖案不算。每軸指定圖案機率調為 1/58，總機率 6/58³ = 6/195,112，約 1/32,519。保留低中獎率的累積大獎玩法；每次 50、保底 100,000、未中獎扣稅後 45 入池、1／10／50 次連轉均沿用。

## 一番賞與回售
每抽独立，無限獎池，沒有保證獲利。

|---|---:|---:|---:|
| A | 2% | 5,000 | 1,000 |
| B | 8% | 300 | 120 |
| C | 30% | 40 | 30 |
| D | 60% | 10 | 8 |

寶島幣每抽 150，期望回售 142，回收率 94.67%。黃金每抽 50，獎品期望回售 43.4，另固定附贈元氣飲，可使用或回售 3 黃金，合計期望 46.4，回收率 92.8%。提高頭獎同時調整普通獎項，避免循環抽取回售產生無限資源。

工作小物按標示價格回售寶島幣；寶島幣用品按購價 50% 回售；黃金用品按購價 10% 向下取整回售黃金。一番賞按上表回售。所有商品在包包與商店可回售，按原幣別退回，不提供任意貨幣互換；回售不恢復每日購買額度。

## 包包
新增獨立入口，分為工作小物、一番賞收藏、生活用品與報紙。只列出持有物品，顯示數量、回售價格；可使用補給、閱讀報紙及逐件回售。物品及貨幣變更同步存檔，重複出售或使用不存在物品會阻擋。

## LINE 與正式營運狀態
已提供條件式 LIFF SDK 載入、登入、回跳後讀取 profile.userId 的流程。需在 dist/config.js 填入實際 liffId，並於 LINE Developers 設定 Endpoint URL 與 profile scope 才能啟用；目前設定空白，因此按鈕停用，不假裝已登入。

LINE 提供的是系統 userId，並非玩家可搜尋的自訂 LINE ID。採用[LINE LIFF 官方 API](https://developers.line.biz/en/reference/liff/#get-profile)。此處僅做前端顯示，正式帳號綁定仍需後端驗證 token 與保管玩家帳本。私人網站仍只供擁有者試玩。

維持裝置端原型：黃金付款、多人城市、共用獎池、全服廣播、跨玩家股票發行額度仍待伺服器串接。所有資源不可兌現；線上與 localhost 使用各自存檔。
